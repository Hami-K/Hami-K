## Hi, I'm Hami
 
Computer Science student at the University of Wollongong in Dubai, majoring in Artificial Intelligence and Big Data. I like building things that solve real problems, from LLM agents to low-level hardware tools.
 
### Featured projects
 
**[heatlog](https://github.com/Hami-K/heatlog)** · Rust  
A Windows hardware monitor for gaming sessions. It records CPU/GPU temperatures, clocks and throttling while you play, then explains slowdowns in plain language and points to possible causes. It has a desktop app (egui), a CLI, NVIDIA, Intel and AMD GPU support, an installer and a checksum-verified in-app updater.
 
**[Purchasing Agent](https://github.com/Hami-K/purchasing-agent)** · Python, LangChain, Gemini  
Built during my hotel purchasing internship. Its main use is following up with suppliers on the Pending Market List, a task with no set format that used to be drafted by hand. The tool turns the Excel export into ready-to-review follow-up emails, saving about an hour a day. It also has experimental extras, such as reading supplier price sheets with vision extraction.
 
**[YouTube Intelligence Engine](https://github.com/sjv24/youtube-intelligence-engine)** · Python, LangGraph · *contributor*  
Multi-agent NLP system analysing YouTube comments and screenplay content. I built the aspect-based sentiment analysis module and supported the RAG pipeline.
 
**[Health Insurance Cross-Sell Prediction](https://github.com/Hami-K/insurance-predictor)** · Python, LightGBM  
Group ML project predicting customer cross-sell response. I owned preprocessing, feature engineering and the training pipeline.
 
**[Internly](https://github.com/Hami-K/Internly)** · Node.js, MySQL
